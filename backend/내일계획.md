### 3단계: Prefetch 구조 확인
**파일**: `backend/app/services/vector_store.py` (라인 118-122)

현재 코드:
```python
prefetch = [
    Prefetch(query=dense_query_list, using="dense", limit=20),
    Prefetch(query=sparse_query_obj, using="bm25", limit=20),
]
```

**문제 가능성**:
1. `sparse_query_obj.as_object()`가 잘못된 형식 반환
2. Qdrant 1.12.1 버전에서 Prefetch API 변경
3. bm25 vector가 컬렉션에 없음

**확인 방법**:
```python
# sparse_query_obj 타입 확인
print(f"Type: {type(sparse_query_obj)}")
print(f"Content: {sparse_query_obj}")
```

### 4단계: 결과에 따른 해결 방안

#### Case A: RAG도 에러 발생
→ **Qdrant/fastembed 버전 문제 또는 컬렉션 설정 문제**

**해결책**:
1. Qdrant 버전 업그레이드 (1.12.1 → 최신)
2. 또는 Dense만 사용 (Sparse 제거)

#### Case B: RAG는 정상, 챗봇만 에러
→ **챗봇에서 생성한 쿼리 데이터 형식 문제**

**해결책**:
1. chat_tools.py의 쿼리 변환 로직 확인
2. sparse 쿼리 생성 방식 수정

#### Case C: bm25 vector가 컬렉션에 없음
→ **컬렉션 재생성 필요**

**해결책**:
```bash
python scripts/index_cosmetics_qdrant.py
```

## 조사 스크립트

다음 스크립트를 `backend/scripts/test_qdrant_prefetch.py`로 생성하여 실행:

```python
# backend/scripts/test_qdrant_prefetch.py
import sys
import os
sys.path.append(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from app.core.config.qdrant import get_qdrant_client, QDRANT_HYBRID_COLLECTION
from app.services.vector_store import VectorStoreService
from fastembed import TextEmbedding, SparseTextEmbedding
from qdrant_client.models import Prefetch

print("="*80)
print("Qdrant Prefetch 오류 조사")
print("="*80)

# 1. 컬렉션 정보
print("\n[1] 컬렉션 정보")
try:
    info = VectorStoreService.get_collection_info()
    print(f"  - Points: {info['points_count']}")
    print(f"  - Status: {info['status']}")
    
    client = get_qdrant_client()
    collection = client.get_collection(QDRANT_HYBRID_COLLECTION)
    print(f"  - Vectors config: {collection.config.params.vectors.keys()}")
except Exception as e:
    print(f"  [ERROR] {e}")

# 2. 쿼리 생성 테스트
print("\n[2] 쿼리 생성 테스트")
try:
    dense_model = TextEmbedding("intfloat/multilingual-e5-large")
    sparse_model = SparseTextEmbedding("Qdrant/bm25")
    
    dense_query = list(dense_model.query_embed("여드름 케어"))[0]
    sparse_query = list(sparse_model.query_embed("여드름 살리실산"))[0]
    
    dense_query_list = dense_query.tolist() if hasattr(dense_query, 'tolist') else list(dense_query)
    sparse_query_obj = sparse_query.as_object()
    
    print(f"  - Dense query type: {type(dense_query_list)}, len: {len(dense_query_list)}")
    print(f"  - Sparse query type: {type(sparse_query_obj)}")
    print(f"  - Sparse query: {sparse_query_obj}")
except Exception as e:
    print(f"  [ERROR] {e}")
    import traceback
    traceback.print_exc()

# 3. Prefetch 테스트
print("\n[3] Prefetch 테스트")
try:
    prefetch = [
        Prefetch(query=dense_query_list, using="dense", limit=20),
        Prefetch(query=sparse_query_obj, using="bm25", limit=20),
    ]
    print(f"  - Prefetch 생성 성공")
    print(f"  - Prefetch[0]: {prefetch[0]}")
    print(f"  - Prefetch[1]: {prefetch[1]}")
except Exception as e:
    print(f"  [ERROR] Prefetch 생성 실패: {e}")
    import traceback
    traceback.print_exc()

# 4. 실제 검색 테스트
print("\n[4] 실제 검색 테스트")
try:
    client = get_qdrant_client()
    results = client.query_points(
        collection_name=QDRANT_HYBRID_COLLECTION,
        prefetch=prefetch,
        query=dense_query_list,
        using="dense",
        limit=5,
        with_payload=True
    )
    print(f"  - 검색 성공! 결과: {len(results.points)}개")
except Exception as e:
    print(f"  [ERROR] 검색 실패: {e}")
    import traceback
    traceback.print_exc()

print("\n" + "="*80)
print("조사 완료")
print("="*80)
```
